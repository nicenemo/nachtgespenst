Demos

What else the boards can do, and how it was measured.

Demos. The Java program that drives the boards for these demos (the desktop app) is not public. Its demo window is rebuilt for the browser, with a pretend board, on Try it, and that code is public. The macropad and the clicker themselves do not need any of it.

The boards started as a macro pad, and the same hardware has been used for more: a host that sets the lamps of the LED bar, a webcam that checks the colours of the bars, and a file that travels to the board and back over the lamps and the game pad buttons. These pages describe those demonstrations and what was measured. The macro pad and the clicker do not depend on any of it.

LampArray bench

The LED bar and the screen as lamps a computer can set, measured over USB and Bluetooth.

Camera tests

A webcam finds the LED bar pin and checks the colour of every layer and every lock state.

The shell manual lists every command of the boards; the commands of the demos are part of it.
