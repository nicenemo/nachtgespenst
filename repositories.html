Repositories

Where the public code lives, and what is still to come.

Published

  • nachtgespenst: this site (plain HTML, CSS and a little JavaScript), with the licence and the third-party notices. MIT licence.

Planned

These repositories are not published yet. They are listed so that it is clear how the project is meant to be delivered: the macro pad and the clicker each on their own, on a shared library, and buildable with PlatformIO alone. The names are working names and may change.

  • ng-core: the C++ libraries that the products share: the HID reports and transports (USB and Bluetooth LE), the LED bar, the shell and its manual, the touch interface and the logging.
  • ng-macropad: the firmware of the macro pad for the M5Stack Core2 and CoreS3: the key pages and the Locks page, built on ng-core.
  • ng-clicker: the firmware of the presentation clicker, with the air mouse, built on ng-core.
  • ng-tools: the host tools in Java for the boards: flashing, the serial shell, the automated test of a board, and the generators for the HID vocabulary and the shell manual.

The demos on this site are not part of these repositories, and their sources are not publicly available.
